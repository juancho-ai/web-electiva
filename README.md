# Proyecto Final: Nicole Oresme y Luca Pacioli

## Estructura del Proyecto
```text
proyecto_oresme_pacioli/
├── index.html      # Estructura HTML de las 10 pestañas y componentes
├── css/
│   └── styles.css  # Estilos responsivos, animaciones, tarjetas 3D y tema visual
├── js/
│   └── app.js      # Navegación por pestañas, simuladores matemáticos, podcast y juegos
└── README.md       # Instrucciones de uso y despliegue
```

## Cómo ejecutarlo o subirlo a internet
1. **En tu computador:** Abre directamente `index.html` en cualquier navegador (Chrome, Edge, Firefox, Safari).
2. **En GitHub Pages o Netlify:** Sube la carpeta completa `proyecto_oresme_pacioli` (manteniendo la estructura de carpetas `css/` y `js/`) para obtener el enlace público.
